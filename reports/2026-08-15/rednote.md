## 标题

本周AI Agent项目大盘点🔥

## 正文

这周趋势明显:大家不再只造"更强的编程 Agent",而是琢磨让一堆 Agent 协同、共享记忆、被管住。挑了 10 个本周涨星最猛的项目。

1️⃣ **diagram-design**
Claude Code 配图技能,一句话生成编辑级架构图。本周涨星近 1.5 万,冲榜首。
🔗 github.com/cathrynlavery/diagram-design

2️⃣ **prime-agent**
自我改进编程/研究 Agent,子任务像函数一样递归展开。
🔗 github.com/PrimeIntellect-ai/prime-agent

3️⃣ **orca**
同时开多个编程 Agent 并行干活,各跑分支挑最好合并。
🔗 github.com/stablyai/orca

4️⃣ **pi**
统一多家大模型 API 的工具包,不少编排项目的底层引擎。
🔗 github.com/earendil-works/pi

5️⃣ **agent-skills**
工程师经验打包成技能,一条命令跑完规划到审查。
🔗 github.com/addyosmani/agent-skills


6️⃣ **TencentDB-Agent-Memory**
腾讯云的 Agent 记忆中枢,不同 Agent 共用团队记忆。
🔗 github.com/TencentCloud/TencentDB-Agent-Memory

7️⃣ **anthropics/skills**
Anthropic 官方技能范例库,不少是 Claude 文档生成功能背后的真实实现。
🔗 github.com/anthropics/skills

8️⃣ **code-graph-rag**
给代码仓库建知识图谱,自然语言查询改代码,比向量检索更懂结构。
🔗 github.com/vitali87/code-graph-rag

9️⃣ **Switchyard**
Rust 写的大模型流量网关,跨厂商 API 转换路由,接自建模型对比成本。
🔗 github.com/NVIDIA-NeMo/Switchyard

🔟 **loopx**
专做"治理"的 Agent 面板,管理长任务进度和证据链,关键决定留给人。
🔗 github.com/huangruiteng/loopx

你用哪个~
