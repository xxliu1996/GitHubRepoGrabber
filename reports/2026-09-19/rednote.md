## 正文

这周 GitHub 涨星最猛的 10 个 Agent 项目👇

1️⃣ **alibaba/open-code-review**
阿里开源代码审查工具，接入多种 AI 编程助手统一审查。
🔗 github.com/alibaba/open-code-review

2️⃣ **Tencent/WeKnora**
腾讯开源知识库框架，RAG 问答加自主检索，自动生成百科。
🔗 github.com/Tencent/WeKnora

3️⃣ **stablyai/orca**
让多个编程 Agent 并行干活，一份提示词分发多 Agent 对比结果。
🔗 github.com/stablyai/orca

4️⃣ **Panniantong/Agent-Reach**
给 AI Agent 装上看全网的眼睛，一键接入 Twitter、小红书。
🔗 github.com/Panniantong/Agent-Reach

5️⃣ **addyosmani/agent-skills**
资深工程师最佳实践打包成技能，装进 70 多种 Agent 工具。
🔗 github.com/addyosmani/agent-skills

6️⃣ **danny-avila/LibreChat**
自托管多模型聊天平台，可管理 Agent、执行代码。
🔗 github.com/danny-avila/LibreChat

7️⃣ **melgarafael/DeskcommCRM**
自托管 CRM，AI Agent 在 WhatsApp 接待促单。
🔗 github.com/melgarafael/DeskcommCRM

8️⃣ **vxcontrol/pentagi**
安全研究人员的自动化渗透测试系统，多智能体测试。
🔗 github.com/vxcontrol/pentagi

9️⃣ **bojieli/ai-agent-book**
中文电子书，讲透 Agent 设计原理，含 109 个实验。
🔗 github.com/bojieli/ai-agent-book

🔟 **alphaXiv/OpenResearch**
把编程 Agent 变成科研助手，审文献跑实验，数据留本地。
🔗 github.com/alphaXiv/OpenResearch
