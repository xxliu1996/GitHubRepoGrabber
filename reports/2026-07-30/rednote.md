## 标题（≤20 字）

本周 GitHub 最火 Agent 项目 🔥

## 正文

这周 GitHub 上最火的不是"更聪明的 AI"，而是"怎么管好一群 AI"。从 Skills 集合、多 Agent 编排、专属浏览器，到代码审查和治理护栏，全是在解决"Agent 多了之后怎么办"的问题。挑了 10 个值得存的开源项目，涨星数都是本周实测 📈

1️⃣ **mattpocock/skills**
一套"给真实工程师用"的 Agent Skills 集合，小巧可组合、不绑定模型，一周暴涨 1.2 万星。想让编程 Agent 少说废话、干活更利落，直接抄作业。
🔗 github.com/mattpocock/skills

2️⃣ **bojieli/ai-agent-book**
一本开源中文书，系统讲透 Agent = LLM + 上下文 + 工具，配 94 个可动手实验。想搞懂 Agent 底层原理而不只是会用，这本书很适合。
🔗 github.com/bojieli/ai-agent-book

3️⃣ **diegosouzapw/OmniRoute**
免费 AI 网关，一个接口打通 290 多个服务商、500 多个模型，自动故障转移还能省 15%-95% token。用 Claude Code、Cursor 的人可以少踩限流的坑。
🔗 github.com/diegosouzapw/OmniRoute

4️⃣ **stablyai/orca**
桌面端 Agent 编排工具，能同时跑 Claude Code、Codex 等多个编程 Agent，各自在独立工作区并行干活，手机上也能远程盯着。适合想让 Agent 24 小时连轴转的人。
🔗 github.com/stablyai/orca

5️⃣ **alibaba/open-code-review**
阿里内部代码审查工具的开源版，用"工程逻辑 + Agent"混合架构做行级精准评审，精度更高、token 消耗只要九分之一。团队想上自动化 Code Review 可以直接用。
🔗 github.com/alibaba/open-code-review

6️⃣ **citrolabs/ego-lite**
专为人机共用设计的 macOS 浏览器，Agent 在独立空间跑自动化，不打扰你自己的标签页，还能直接复用你的登录状态。做网页自动化的开发者会很香。
🔗 github.com/citrolabs/ego-lite

7️⃣ **tirth8205/code-review-graph**
给代码库建一张结构化知识图谱，让 AI 工具只读真正相关的部分，token 压缩比最高能到 500 多倍。大仓库用 AI 编程助手卡顿的可以试试。
🔗 github.com/tirth8205/code-review-graph

8️⃣ **infiniflow/ragflow**
老牌开源 RAG 引擎，靠深度文档理解把企业文档变成可精准检索、可追溯来源的知识库。想搭企业级问答系统绕不开它。
🔗 github.com/infiniflow/ragflow

9️⃣ **microsoft/agent-governance-toolkit**
微软出的 Agent 治理工具包，给生产环境的自主 Agent 加上权限管控、身份认证和审计能力，覆盖 OWASP 十大安全风险。要把 Agent 真正用到线上、过合规的必看。
🔗 github.com/microsoft/agent-governance-toolkit

🔟 **MoonshotAI/kimi-code**
月之暗面出的终端编程 Agent，支持丢视频进去讲需求，单文件二进制免安装，还能直接接进 Zed、JetBrains。喜欢在终端里工作的可以关注下。
🔗 github.com/MoonshotAI/kimi-code
