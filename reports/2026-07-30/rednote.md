## 标题

本周最火的 10 个 Agent 项目 🔥

## 正文

这周 GitHub 周榜变了：大家不卷做新 agent，改卷怎么调教手里的 Claude Code。十个里六个是外挂工具。先收藏👇

1️⃣ mattpocock/skills
本周暴涨 1.2 万星，专治 agent 四大毛病：不听话、话多、代码烂、架构烂。
🔗 github.com/mattpocock/skills

2️⃣ bojieli/ai-agent-book
中文原创 Agent 工程书，全文加 94 个实验全开源，想系统学的别错过。
🔗 github.com/bojieli/ai-agent-book

3️⃣ diegosouzapw/OmniRoute
290 多家模型商合并成一个接口，90 多家免费，烧 token 心疼的进。
🔗 github.com/diegosouzapw/OmniRoute

4️⃣ stablyai/orca
30 多种编码 agent 跑在隔离分支里，对比谁写得好再合并。
🔗 github.com/stablyai/orca

5️⃣ alibaba/open-code-review
阿里内部几千人在用的评审工具，精确到行给意见。
🔗 github.com/alibaba/open-code-review

6️⃣ citrolabs/ego-lite
给 agent 用的浏览器，它后台跑自动化你还能正常上网，继承 Chrome 登录态。
🔗 github.com/citrolabs/ego-lite

7️⃣ ayghri/i-have-adhd
十条硬规则逼 AI 说人话：先说结论，不许铺垫。
🔗 github.com/ayghri/i-have-adhd

8️⃣ earendil-works/pi
想自建编程 agent 的看这个，模型接口到终端界面全给你。
🔗 github.com/earendil-works/pi

9️⃣ tirth8205/code-review-graph
给代码库画调用关系图，改动时只喂受影响的部分。
🔗 github.com/tirth8205/code-review-graph

🔟 infiniflow/ragflow
老牌开源 RAG 引擎，最强的是啃复杂 PDF，扫描件都能拆。
🔗 github.com/infiniflow/ragflow

你在用哪个？评论区聊👇
