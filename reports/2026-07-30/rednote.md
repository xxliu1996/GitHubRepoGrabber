## 标题

本周最火 10 个 Agent 项目 🔥

## 正文

这周 GitHub 火的不是"更聪明的 AI"，而是"怎么管好一群 AI"。10 个都是本周实测涨星👇

1️⃣ mattpocock/skills
小巧可组合的 Agent Skills 集合，一周暴涨 1.2 万星。
🔗 github.com/mattpocock/skills

2️⃣ bojieli/ai-agent-book
开源中文书，讲透 Agent 原理，配 94 个实验。
🔗 github.com/bojieli/ai-agent-book

3️⃣ diegosouzapw/OmniRoute
一个接口打通 290 多家模型商，90 多家免费。
🔗 github.com/diegosouzapw/OmniRoute

4️⃣ stablyai/orca
多个编程 Agent 并行跑在独立工作区，手机可远程盯。
🔗 github.com/stablyai/orca

5️⃣ alibaba/open-code-review
阿里代码审查工具开源版，行级精准评审。
🔗 github.com/alibaba/open-code-review

6️⃣ citrolabs/ego-lite
人机共用的浏览器，Agent 跑自动化不打扰你。
🔗 github.com/citrolabs/ego-lite

7️⃣ tirth8205/code-review-graph
给代码库建知识图谱，只喂 AI 相关部分。
🔗 github.com/tirth8205/code-review-graph

8️⃣ infiniflow/ragflow
老牌 RAG 引擎，啃复杂文档、答案可溯源。
🔗 github.com/infiniflow/ragflow

9️⃣ microsoft/agent-governance-toolkit
微软出品，给线上 Agent 加权限管控和审计。
🔗 github.com/microsoft/agent-governance-toolkit

🔟 MoonshotAI/kimi-code
月之暗面的终端编程 Agent，单文件免安装。
🔗 github.com/MoonshotAI/kimi-code
