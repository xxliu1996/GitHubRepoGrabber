## 标题

本周10个爆火Agent项目🔥

## 正文

Agent 圈这周卷的是基础设施：记忆、交接、路由。整理本周涨星最快的 10 个项目，收藏慢慢看。

1️⃣ TencentDB-Agent-Memory
把对话文档代码沉淀成可复用记忆，让团队多个 Agent 共享。
🔗 github.com/TencentCloud/TencentDB-Agent-Memory

2️⃣ OmniRoute
免费 AI 网关，一个接口接入近 300 家模型商，自动省 token、切配额。
🔗 github.com/diegosouzapw/OmniRoute

3️⃣ DeepSeek-Reasonix
终端里跑的编码 Agent，单文件零依赖，缓存命中率优化过。
🔗 github.com/esengine/DeepSeek-Reasonix

4️⃣ loopx
多 Agent 团队用的状态内核，记目标待办和日志，交接进度不失控。
🔗 github.com/huangruiteng/loopx

5️⃣ open-code-review
阿里出品，规则加 LLM 双管齐下，精确到行给评审意见，省 token。
🔗 github.com/alibaba/open-code-review

6️⃣ google/skills
谷歌官方 Agent Skills 合集，一行命令装进 Claude Code，专治云服务问题
🔗 github.com/google/skills

7️⃣ FalkorDB
稀疏矩阵做底层的图数据库，专为 LLM 知识图谱和 GraphRAG 而生。
🔗 github.com/FalkorDB/FalkorDB

8️⃣ agent-browser
纯 Rust 浏览器自动化工具，用语义定位代替脆弱的 CSS 选择器。
🔗 github.com/vercel-labs/agent-browser

9️⃣ livekit/agents
实时语音 Agent 框架，能听会说还能看，支持接电话，随意组合服务商。
🔗 github.com/livekit/agents

🔟 ai-agents-for-beginners
微软 18 节 Agent 入门课，零基础可学，覆盖设计模式到安全部署。
🔗 github.com/microsoft/ai-agents-for-beginners
