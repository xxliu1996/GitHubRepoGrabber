GitHub 周报：AI 智能眼镜（2026-11-08 – 2026-11-15）

AI 智能眼镜 2026-11-08 – 2026-11-15 6 个项目

智能眼镜固件、HUD 应用、可穿戴 AI 助手

本周 AI 智能眼镜赛道呈现出显著的「硬件脱钩（De-platforming）」与「第一视角持久记忆（Egocentric Memory）」探索热潮。随着以 Meta Ray-Ban、雷鸟 RayNeo 为代表的消费级智能眼镜出货量增长，开发者愈发不满足于大厂官方 App 的黑盒生态与云端隐私绑架：macedonga 的 visor 与 straff2002 的 OpenGlasses（Avenkin）双双致力于逆向解耦 Meta 眼镜客户端，允许用户自主接入开源本地大模型与专属 Agent 指令；Turbo1123 的 Turbo-IO 则持续攻坚雷鸟 iO 的底层固件、投屏与矢量导航扩展；Iam5tillLearning 推动基于国产嵌入式 Linux 芯片的开源智能眼镜完整硬件与应用参考栈；而在核心算法侧，浙江大学团队开源的 LightMem-Ego 攻克了智能眼镜第一视角多模态生活常驻记忆构建难题，配合可自托管的穿戴健康与 MCP 聚合框架 Mirobody，整个开源生态正在为真正属于用户自己的下一代“全天候外挂大脑”铺平软硬件基石。

1. Turbo1123/Turbo-IO

雷鸟 iO / RayNeo iO 非官方 SDK：原生鸿蒙 HarmonyOS SDK/客户端、iOS 客户端及 iOS/Android 官方 App 扩展。自有模型、联网搜索、眼镜导航、录音研究、Codex 与 Web 预览，各平台能力以文档为准。面向开发者，仅供非商业学习研究；只提供源码，不提供 IPA/APK/HAP 或签名包。
  • ⭐ 总计 348 ⭐（本周增量未测得） ｜ Objective-C ｜ NOASSERTION

面向雷鸟 iO 消费级 AR 智能眼镜的非官方开发者 SDK 与实验性固件扩展项目，覆盖 iOS、Android 与原生鸿蒙历史工程。专为渴望跳出官方功能局限、挖掘眼镜硬件潜能的极客开发者打造。项目不仅实现了自定义小模型接入、实时联网检索与眼镜端微型应用仪表盘，还深度攻坚了 540×220 原生高清投屏、低延迟音频传输以及基于矢量路网的 HUD HUD 小地图转弯导航。

2. macedonga/visor

A de-metaified Meta Glasses client.
  • ⭐ 总计 220 ⭐（本周增量未测得） ｜ Kotlin ｜ AGPL-3.0
  • 主页：https://visor.macedonga.com

旨在彻底取代 Meta 官方 Meta View 应用的开源去中心化 Android 客户端。专为持有 Meta Ray-Ban 智能眼镜但对 Facebook 云端隐私收集存有顾虑、希望掌控全部数据流向的用户与开发者设计。它拦截并接管眼镜的蓝牙/Wi-Fi 通信协议，确保抓拍照片完全保留在手机本地，并将原本锁死在 Meta 官方云的语音唤醒词定向重定向至用户自选的开源模型或本地推理引擎。

3. straff2002/OpenGlasses

Making Meta Ray-ban / Oakley glasses smarter. Non-Meta Model selection, agentic features, smart guidance.
  • ⭐ 总计 133 ⭐（本周增量未测得） ｜ Swift ｜ NOASSERTION
  • 主页：https://testflight.apple.com/join/1dcAytte

为 Meta Ray-Ban 及 Oakley 智能眼镜打造的第三方智能化增强助手应用（Avenkin），提供更开放的端侧多模态问答。面向希望将智能眼镜打造成贴身第二大脑的 iOS 用户与现场作业技术人员。它赋予智能眼镜视觉理解、即时名片收录、票据提取与实时视线引导能力，允许用户根据偏好自由配置第三方商业大模型或完全离线运行于 iPhone 端侧的小模型，杜绝强制平台订阅绑定。

4. Iam5tillLearning/OpenSource-Ai-Glasses

Open-source standalone AI glasses platform built on embedded Linux, with system-level customization, C/C++ SDK, RTSP video streaming, BLE, audio, camera, and optional display support.
  • ⭐ 总计 314 ⭐（本周增量未测得） ｜ C ｜ Apache-2.0

基于嵌入式 Linux 打造的全开源独立智能眼镜软硬件参考架构，主控适配瑞芯微 RV1106B 系列等高能效端侧芯片。面向硬件极客、医疗巡检及工业可穿戴设备研发人员，摆脱专有黑盒穿戴芯片方案的束缚。系统完整集成了 C/C++ 应用开发 SDK、低延迟 RTSP 视频流服务、BLE 蓝牙双模音频、广角摄像头采编管线以及微显示驱动模块，支持开发者快速二次定制专用头显固件。

5. zjunlp/LightMem-Ego

[EMNLP 2026] LightMem-Ego: Your AI Memory for Everyday Life
  • ⭐ 总计 127 ⭐（本周增量未测得） ｜ Python ｜ MIT
  • 主页：https://lightmem-ego.zjukg.cn/

浙江大学 NLP 团队入选顶级会议的智能眼镜第一视角常驻多模态记忆系统（AAAI 2027 Demo / EMNLP 2026）。面向智能眼镜与智能手机等全天候第一人称随身穿戴设备，攻关“模型如何真正记住我所见所闻”的长时记忆难题。它突破了常规多模态模型输入窗口暴涨与上下文遗忘的致命缺陷，将持续的第一视角视频流与环境声音压缩编码为轻量级情节记忆图谱，支持毫秒级的生活细节自然语言回溯与主动联想。

6. thetahealth/mirobody

Mirror your body in data. One standard, every source, one complete picture of you: a self-hosted health record built from lab reports, wearables and genetics, with every number traced to its source and a built-in MCP server. Run it with Docker and one LLM key, or keep every model local on llama.cpp.
  • ⭐ 总计 1515 ⭐（本周增量未测得） ｜ Python ｜ Apache-2.0
  • 主页：https://mirobody.ai/

可自托管的个人多模态可穿戴健康数据中心，统一汇聚来自智能眼镜、体征手环、化验报告与基因测序的多元生命指征。专为关注健康隐私、希望拥有数字身体画像的个人用户及健康智能体开发者设计。它提供标准化的数据溯源追踪与开箱即用的 MCP（Model Context Protocol）服务接口，支持完全运行在本地 llama.cpp 上，让佩戴智能眼镜的 AI 伴侣能够在绝对保护隐私的前提下即时查询用户的生理负荷与健康走势。
